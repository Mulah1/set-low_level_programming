# 0x00-hello_world
0x00 Hello World project This project demonstrates how to use the C preprocessor. The script 0-preprocessor runs a C file stored in $CFILE through the preprocessor and saves output into file c.
This directory contains scripts and C programs for the C compilation and basic output course.

## Tasks:
- **0-preprocessor**: Runs C code through the preprocessor
- **1-compiler**: Compiles C code without linking
- **2-assembler**: Generates assembly code from C
- **3-name**: Compiles C code to executable named cisfun
- **4-puts.c**: Prints using puts() function
- **5-printf.c**: Prints using printf() function
- **6-size.c**: Displays sizes of different data types
